# 重构第三批：连接资源生命周期与状态事件统一

日期：2026-11-03。接续第二批连接业务服务，保留已有功能和持久化数据格式。

## 实施计划与完成情况

1. 已完成：统一运行连接登记。区分保存的 hostId、运行实例 connectionId、用户/Agent 归属和 AI sessionId。
2. 已完成：统一生命周期边界。拨号、重连、关闭按 generation 隔离，借用资源随所属传输失效而释放。
3. 已完成：统一连接状态镜像。主进程提供带 revision 的快照和事件，界面订阅一个入口。
4. 已完成：执行完整单元、类型、lint、构建、桌面和真实 SSH 回归。

## 具体改动

- 新增 shared/connectionState.ts 与 main/ssh/connectionRegistry.ts。每个用户/会话/主机组合保留当前实例；旧实例、旧拨号版本的回调不能覆盖新实例。
- 主进程统一提供 connections:runtime 快照和 connections:state 事件。快照有版本水位，增量有递增版本和删除标记。
- 渲染层 links store 订阅一次并复用，先订阅再拉快照；快照到达后重放较新事件，忽略过期事件、退订后的回调和已删除实例的旧快照。
- 连接列表、拓扑图、主机工作区与资源面板共享该镜像。删除三套重复快照/订阅代码，旧 listLinks 改为统一登记表的兼容投影。
- 保留主机聚合规则：任一用户或 Agent 链路在线，主机仍显示在线；用户终端只跟随自身链路，资源查看工作区跟随可用链路。
- HostLink 关闭幂等；中止尚在握手的目标连接、跳板连接、转发等待和重试等待。旧拨号失败或成功均不得污染新版本，旧系统探测结果也被丢弃。
- 资源面板借用 Agent 的 SSH 传输时登记独立 SFTP 生命周期。传输丢失立即释放借用通道并通知界面；关闭面板不会关闭 Agent 自己的 SFTP。
- 删除主机的异步清理期间禁止新建或重启该主机连接。完成后清除登记状态；失败时解除限制，保留原有重试语义。
- AI 对话延迟回收绑定当时的 connectionId，不能误关后来重建的连接；从索引移除后再通知清理，避免回调重入重复关闭。
- SFTP 启动等待、目录加载和恢复刷新校验面板版本，关闭/重开后不再接收旧结果，也不会继续为旧面板发起下一步查询。
- 真实交互终端回归发现 PowerShell 将初始命令的默认 LF 当作续行；默认提交改为 PTY 标准 CR，调用方明确提供的行尾和逐键输入保持原样。

## 边界与后续顺序

本批统一的是连接层状态。Shell 输出、SFTP 传输进度、性能采样仍使用各自的通道，未将高频数据混入连接事件。旧 IPC 保留兼容，但当前界面的连接状态已全部迁移到新入口。

版本号仅在当前主进程内有效，未引入跨进程重启的持久事件日志。断开记录保留用于拓扑倒计时，并在后续快照读取时清理超过五分钟的记录。原有凭据/配置补偿仍不是跨文件事务。

后续按小批次推进：先统一 Shell、SFTP 和性能采样的资源标识与失效规则，再收敛工作区恢复和错误呈现，最后拆分 IPC 与大型页面。每批均先补关键竞态测试，再迁移调用点并回归；不同时重写终端内核、AI 引擎和存储格式。
