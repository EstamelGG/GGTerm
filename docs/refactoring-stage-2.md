## 统一连接入口

新增 src/main/connections.ts，供主进程 IPC 和 Agent 工具共同调用。

- 创建、修改：凭据与配置一次提交，凭据先保存，再发布配置变更；配置保存失败时尝试恢复原凭据，补偿也失败则明确报告复合错误。
- 界面表单和手动登录保存不再先更新配置、再单独保存凭据；渲染层不再执行自己的回滚流程。
- 成功更新后统一刷新监控；备注仍走独立更新，不触发无关探测重建。
- 删除：统一停止端口转发、资源 SFTP、用户连接和目标主机的全部 Agent 连接，清理凭据和配置，并立即释放监控探测。
- 删除等待期间拒绝同主机的竞争修改和重复删除；清理失败保留记录供重试。
- 分组和备注工具也经统一入口访问已有存储操作，未更改分组级联规则。
- 旧凭据 IPC 入口保留兼容，但写入通过同一业务服务；配置文件格式未迁移。

## 边界及下一步

这是进程内的保存协调与失败补偿，不是跨文件数据库事务；断电或进程崩溃的一致性仍需后续设计。删除已经关闭的连接无法回滚，失败时保留记录也不代表恢复运行任务。Electron 的 vm 提示及部分运行中出现的 Monaco disposable 警告仍需单独排查，未屏蔽控制台输出。

下一步推进连接登记与生命周期版本化，以及状态快照/事件协议。现有数据存储层仍负责广播；这批未同时重写状态同步或依赖体系。
