## 已实现

1. 命令审批：移除 git、find、env、ip 等具有写入或执行参数的宽泛前缀放行。保留明确列出的诊断形式；其余形式在 default/strict 下要求人工确认，即使模型判定器认为安全也不放行。relaxed 行为保留。
2. Agent 修改连接：保存配置及凭据后刷新性能探测，恢复认证失败停等；工具卡 description 不再写入连接配置，只有 description 的调用视为无实际修改。
3. 性能探测：拨号期间监控被删除或替换，迟到连接立即释放；旧认证失败不能阻止新监控；已有共享连接时释放冗余探测连接。
4. Shell 创建：工作区关闭后，迟到的创建结果或终端模块加载结果不能创建残留终端，也不能挂到同主机的新工作区。
5. 新增 Windows/Linux 的类型、lint 和完整测试工作流。检查独立执行，不忽略失败；尚未在 GitHub 上运行。

- 某些只读命令（例如 git log、git diff 或复杂 find 查询）也会请求确认；这是暂时收紧自动放行范围的代价。
