# 重构第七批：偏好、语言、日志与 AI IPC 拆分

日期：2026-11-03。基于第六批检查点 `98dc40a`，完成主 IPC 入口中剩余处理逻辑的模块拆分，保留现有功能和接口。

## 模块职责

- `src/main/ipc/preferences.ts`：偏好读取、写入和主进程偏好变更广播；保留保存后的窗口缩放与性能采样刷新。
- `src/main/ipc/locale.ts`：语言偏好读取与切换；保留主进程语言切换、菜单重建、窗口广播的执行顺序及原有即时回复。
- `src/main/ipc/logs.ts`：日志历史读取、渲染层日志写入与清空。
- `src/main/ipc/ai.ts`：AI 会话列表、创建、消息读取、关闭、运行、取消、模型列表及 API Key 存在检查与保存。
- `src/main/ipc.ts`：从 123 行缩减为 27 行，只保留各模块注册和 `channels` 再导出。

原有 execution、humanInput、question 注册模块继续独立存在，注册顺序保持不变。只读执行查看接口和敏感人工输入接口继续分离，本批没有合并其权限与数据路径。

## 兼容性核对

本批迁移 16 个处理器。对迁移前后的整个 IPC 目录及入口进行了语法级比较：84 个注册的通道表达式、handle/on 类型、参数及回调实现 token 一致；偏好变更广播回调也一致，没有重复注册。通道常量文件、preload、共享类型及底层服务未修改。

- 偏好写入仍返回保存后的完整偏好；只有对应字段出现在 patch 中时，才调整窗口缩放或刷新采样。
- 主进程内部写入偏好仍广播到所有未销毁窗口。
- 语言切换仍即时返回偏好与当时解析的语言，异步语言更新完成后重建菜单并广播。未将既有接口改为等待广播完成后才返回。
- 日志写入、日志清空和 AI 会话关闭仍是单向事件，其余对应操作仍使用请求/响应接口。
- AI 运行和取消仍透传 sessionId、messages、turnId；取消时 turnId 仍可省略。异步结果与错误继续交由原业务服务返回。
- API Key 查询仍只返回是否存在，不返回密钥；保存参数继续兼容原有 `profileId` 字段。
